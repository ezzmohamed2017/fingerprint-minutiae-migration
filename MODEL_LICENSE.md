# Model weights licence

The weights in `fpmig-models-v1.0.0.zip` were trained on the MOLF database (IIIT-Delhi) and evaluated on
FingerDOS. Both datasets are distributed by their providers under their own terms, which typically restrict use to
non-commercial research.

Until the author states otherwise, the model weights are released **for non-commercial research and evaluation
only**, under the Creative Commons Attribution-NonCommercial 4.0 International licence (CC BY-NC 4.0), and subject
to the terms of the training datasets. Commercial deployment requires retraining on data you are licensed to use
(the training code in `training/` is MIT-licensed) or written permission from the author.

The code in this repository is MIT-licensed (see `LICENSE`).
